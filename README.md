## 怎么看 THE PLAN 和常规方案的差别？

如果 THE PLAN 在你的购买时点确实出现在官方订单页，比较时不要只盯着“每年多少钱”。建议把以下几项放在一起看：

**流量是否够用。** 官网公开方案从每月 1TB 到 6TB 不等。轻量网站、测试环境和个人项目，可能更关心内存与存储；大量文件传输或有明显流量峰值的服务，则应该先估算月流量，再比较套餐。不要把端口速率和月流量混为一谈：1Gbps 描述链路速率，TB/月才是流量额度。
